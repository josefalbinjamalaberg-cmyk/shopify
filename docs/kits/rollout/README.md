## Changed files (draft theme 205725663566)

Shared (Stort's rendered text verified identical before/after):

- `sections/nr-kitpage-compare.liquid` – up to two alternatives, price-ordered cards
- `sections/nr-kitpage-included.liquid` – column count by number of components
- `blocks/nr-kitpage-summary.liquid` – `kit_audience` override, `separate_adjust`, optional note
- `blocks/nr-kitpage-points.liquid` – `kit_points` override
- `assets/nr-kitpage.css`

Templates: `templates/product.kit-{interiorlitet,interiormellan,falgstart,falgdack,exteriorstart,foamwash,exteriorkomplett}.json`
(generated by `build.py`).

Metafields (product, `custom`): `kit_display_title`, `kit_audience` (new),
`kit_descriptor`, `kit_points` (new), `kit_component_notes`, `kit_faq` – keys
that the live theme does not read (checked against the live theme's files).
The live-read keys (`kit_eyebrow`, `kit_tagline`, `kit_value_points`,
`kit_card_line`, `kit_fit_points`, `kit_alt_question`) were not changed.
